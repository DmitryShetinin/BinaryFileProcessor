# XOR File Modifier

Desktop-приложение на **C++ / Qt** для пакетной модификации бинарных файлов с использованием XOR-операции и 8-байтного ключа.

Программа предназначена для обработки больших файлов без блокировки пользовательского интерфейса и поддерживает приостановку, возобновление, остановку и периодический поиск новых файлов.

## Возможности

* XOR-модификация входных файлов с 8-байтным ключом в формате HEX
* Обработка больших файлов чанками без загрузки всего файла в память
* Отзывчивый UI во время обработки
* Отображение прогресса обработки
* Pause / Resume с продолжением обработки с текущей позиции
* Cooperative Stop
* Корректное завершение приложения во время обработки
* Разовый запуск или работа в режиме периодического опроса
* Настраиваемый интервал опроса
* Поддержка нескольких масок входных файлов
* Выбор input / output каталогов через системный диалог
* Удаление входных файлов после успешной обработки
* Обработка конфликтов имён:

  * перезапись существующего файла
  * автоматический числовой суффикс (`file_1.bin`, `file_2.bin`, ...)
* Ручной выбор файлов через `QFileDialog`
* Логирование операций и ошибок
* Unit-тесты на базе **Qt Test + CTest**

## Как работает XOR

Пользователь задаёт 8-байтный ключ, например:

```text
1234567890ABCDEF
```

Он интерпретируется как последовательность байтов:

```text
12 34 56 78 90 AB CD EF
```

Ключ циклически повторяется при обработке файла:

```text
data:  AA BB CC DD EE FF 11 22 33 44 ...
key:   12 34 56 78 90 AB CD EF 12 34 ...
```

Для каждого байта выполняется:

```text
output[i] = input[i] XOR key[i % 8]
```

Файл обрабатывается последовательно чанками по **4 MB**, поэтому размер файла практически не влияет на объём необходимой оперативной памяти.

## Архитектура

Проект разделён на несколько уровней ответственности:

```text
MainWindow
    │
    ▼
ProcessingController
    │
    ▼
QThread
    │
    ▼
ProcessingWorker
    ├── FileScanner
    ├── OutputNameResolver
    └── FileProcessor
```

### MainWindow

Отвечает за пользовательский интерфейс, ввод настроек, отображение статуса, прогресса и ошибок.

### ProcessingController

Управляет рабочим потоком и взаимодействием между UI и `ProcessingWorker`.

### ProcessingWorker

Организует процесс обработки файлов, поддерживает:

* Pause
* Resume
* Stop
* Timer Mode
* отслеживание уже обработанных файлов

### FileScanner

Отвечает за поиск входных файлов и обработку масок, например:

```text
.txt
.bin
*.dat
testFile.bin
.txt, .bin, testFile.bin
```

### OutputNameResolver

Определяет имя результирующего файла в зависимости от выбранной политики конфликта.

Например:

```text
Перезаписать:
output/test.bin

Добавить счётчик:
output/test.bin
output/test_1.bin
output/test_2.bin
```

### FileProcessor

Содержит основную логику чтения, XOR-преобразования и записи файла.

## Использование

1. Укажите маску входных файлов.
2. Выберите папку для поиска входных файлов.
3. Выберите папку для сохранения результатов.
4. Выберите поведение при конфликте имён.
5. При необходимости включите удаление входных файлов после успешной обработки.
6. Выберите разовый или таймерный режим.
7. Укажите период опроса.
8. Введите 16 HEX-символов для 8-байтного XOR-ключа.
9. Нажмите **Старт**.

Во время обработки доступны:

```text
Пауза
Продолжить
Стоп
```

В режиме таймера приложение продолжает периодически проверять входной каталог и обрабатывает новые файлы.

## Обработка больших файлов

Приложение не загружает весь файл в память.

Для файла размером 10 GB используется последовательная обработка:

```text
4 MB → XOR → запись
4 MB → XOR → запись
4 MB → XOR → запись
...
```

Это позволяет сохранять отзывчивость интерфейса и ограничивать использование памяти размером рабочего буфера.
